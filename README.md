# Muzflowers — цветочный магазин

Готовый сайт на Django: каталог букетов, корзина, оформление заказа с доставкой, промокоды,
регистрация и личный кабинет с историей заказов, админка для управления магазином.

## Как запустить (3 шага)

1. Установите **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/).
   На Windows при установке поставьте галочку **Add Python to PATH**.
2. Запустите проект:
   - **Windows:** дважды кликните по файлу `start.bat`
   - **Mac / Linux:** в терминале в этой папке выполните `./start.sh`
3. Откройте в браузере **http://127.0.0.1:8000**

При самом первом запуске в окне появится логин и пароль администратора. **Сохраните их**, пароль показывается один раз.
Остановить сайт: `Ctrl + C` в окне.

## Что где открывается

| Адрес | Что это |
|---|---|
| `/` | Сайт: каталог, корзина, оформление заказа |
| `/accounts/register/`, `/accounts/login/` | Регистрация и вход |
| `/accounts/profile/` | Личный кабинет с заказами |
| `/privacy/` | Политика конфиденциальности (шаблон — проверьте текст) |
| `/admin/` | Админка магазина |

## Как управлять магазином (в админке)

- **Букеты** → добавить, поменять цену, загрузить фото, скрыть с сайта. Без фото рисуется цветок по двум цветам.
- **Категории** → разделы каталога (Розы, Пионы...).
- **Заказы** → смотреть новые заказы и менять статус (Новый → Подтверждён → В доставке → Выполнен).
- **Промокоды** → создать код и процент скидки. Демо-код: `MUZ10`.
- **Отзывы** → то, что показывается на главной. Демо-отзывы замените настоящими.

## Как поменять контакты и условия доставки

Откройте файл `.env` (он появится после первого запуска), поменяйте телефон, адрес, часы работы,
цену доставки и порог бесплатной доставки, затем перезапустите сайт.
Тексты на странице («Почему мы», заголовки) лежат в `templates/shop/index.html`.

## Структура проекта

    manage.py               запуск команд Django
    start.bat / start.sh    запуск сайта одним кликом
    .env.example            шаблон настроек (из него создаётся .env)
    requirements.txt        нужные пакеты
    muzflowers/             настройки проекта (settings.py, urls.py)
    shop/                   магазин: модели, заказы, админка, демо-данные
    accounts/               регистрация, вход, личный кабинет
    templates/              HTML-страницы (base.html — общий каркас)
    static/shop/            стили и скрипты сайта

## Как это устроено внутри

- Цены, скидки и доставку **всегда считает сервер** по данным из базы, браузеру не доверяем.
- Защита форм (CSRF), проверка всех полей, лимиты на заказы, промокоды, вход и регистрацию.
- Данные из базы экранируются перед показом на странице.

## Перед выкладкой в интернет

1. В `.env` поставьте `DJANGO_DEBUG=0`, задайте длинный `DJANGO_SECRET_KEY`,
   `DJANGO_ALLOWED_HOSTS` (ваш домен) и `DJANGO_CSRF_ORIGINS=https://ваш-домен`.
2. Нужен **HTTPS**. Если сайт стоит за nginx, добавьте `DJANGO_BEHIND_PROXY=1` и `SHOP_CLIENT_IP_HEADER=HTTP_X_REAL_IP`
   (nginx должен сам выставлять `X-Real-IP`).
3. Выполните `python manage.py collectstatic --noinput` и `python manage.py check --deploy`.
4. Запускайте через gunicorn/uwsgi (`muzflowers.wsgi:application`), а не через `runserver`.
5. Смените адрес админки (`DJANGO_ADMIN_URL`), задайте сложный пароль админа.
6. Для лимитов на нескольких процессах подключите Redis (`REDIS_URL=redis://...`, пакет `redis`).
7. Фото букетов (`media/`) отдавайте через nginx или включите `DJANGO_SERVE_MEDIA=1` для небольшого магазина.
8. Проверьте текст политики конфиденциальности (`templates/shop/privacy.html`) с юристом: требования зависят от страны.
9. Регулярно делайте копию `db.sqlite3` и папки `media/`.
